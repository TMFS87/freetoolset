# FreeToolset

> 75+ free online tools + AI writing studio. Privacy-first, runs 100% in your browser.

🌐 **Live site:** https://www.freetoolset.app

FreeToolset is a free, no-signup toolbox covering the everyday utilities people actually need:

- 🤖 **AI Writing Tools** — product descriptions, blog posts, SEO meta, email subjects, content rewriter, all powered by AI
- 🧮 **Calculators** — BMI, loan, mortgage, ROI, compound interest, salary, calorie, and more (15 tools)
- 🔄 **Converters** — unit, temperature, length, weight, speed, data storage, Roman numerals, number-to-words
- 📝 **Text Tools** — word counter, case converter, line tools, find & replace, text-to-speech
- 🛠 **Developer Tools** — JSON formatter/minifier, Base64, JWT decoder, regex tester, cron generator, hash/UUID
- 🔐 **Security** — password generator & strength checker, hash generator
- 🎲 **Fun** — dice roller, random number, countdown timer, stopwatch, Morse code

## Why FreeToolset

- **Privacy-first:** tools run locally in your browser - your data never leaves the device.
- **No account needed:** open and use instantly.
- **AI Studio:** a single assistant that writes, generates, and reformats anything you ask.
- **Free & open:** no paywalls on core tools.
