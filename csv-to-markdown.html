📊 CSV to Markdown Table

Convert a CSV file or pasted text into a Markdown table. Handles quoted fields, commas and embedded newlines.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste CSV text or load a file.
  2. Click Convert.
  3. Copy the Markdown table.
  4. The first row becomes the header.

❓ FAQ

Does it handle quoted commas?

Yes — fields wrapped in quotes containing commas or newlines are parsed correctly.

What becomes the header?

The first row of the CSV is used as the table header; every following row becomes a table row.

Is my data uploaded?

No — parsing happens in your browser.

❓ 常见问题（中文）

能处理带引号的逗号吗？

能。被引号包裹、内含逗号或换行的字段会被正确解析。

表头是哪一行？

CSV 的第一行作为表头，之后的每一行作为表格的一行。
