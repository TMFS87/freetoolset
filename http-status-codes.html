❓ FAQ

What do the code categories mean?

1xx informational, 2xx success, 3xx redirection, 4xx client errors, 5xx server errors.

What is the difference between 401 and 403?

401 Unauthorized means authentication is required or failed; 403 Forbidden means you are authenticated but not allowed.

When is 500 used?

500 Internal Server Error is a generic message when the server hits an unexpected condition.
