❓ FAQ

Does it preserve nesting and arrays?

Yes — objects, arrays, strings, numbers, booleans and null are all converted with correct indentation and list dashes.

Why would I convert JSON to YAML?

YAML is far more readable for humans and is the preferred format for many DevOps config files, while JSON is stricter and machine-friendly.

Is my data uploaded?

No. Conversion runs entirely in your browser; nothing is sent to a server.

📖 深入了解 JSON to YAML Converter

为什么需要 JSON → YAML

JSON 机器友好但可读性差；YAML 用缩进表达层级，人在写配置时更舒服。Kubernetes、Docker Compose、GitHub Actions 等几乎都用 YAML。

本工具能处理什么

  • 对象（键值对）→ 缩进的 key: value
  • 数组 → 以 “- ” 开头的列表
  • 字符串、数字、布尔、null 均正确表达
  • 需要加引号的字符串会自动加引号

    • 使用建议

  • 粘贴前确保 JSON 合法（可用 JSON 校验工具先检查）
  • 结果可直接复制到 .yml 文件
