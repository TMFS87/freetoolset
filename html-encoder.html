HTML Encoder / Decoder

Encode text to HTML entities or decode HTML entities back to plain text. Safely escape <, >, & and quotes for the web.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste text or HTML into the input box.
  2. Click Encode to escape special characters.
  3. Or click Decode to convert entities back.
  4. Copy the converted output.

❓ FAQ

Why encode HTML?

Encoding turns characters like < and & into entities so they display as text instead of being interpreted as markup — essential for showing code safely.

Which characters are encoded?

The core special characters &, <, >, " and ' are converted; decoding also understands named and numeric entities.

Does it prevent XSS?

Escaping output is one important defense, but always combine it with proper server-side sanitization.

HTML编码解码器需要联网吗？

不需要。所有处理都在你的浏览器本地完成，数据不上传服务器，离线也能用。

HTML编码解码器支持大文件或批量吗？

在浏览器性能范围内支持较大内容处理；具体上限取决于你的设备内存。
