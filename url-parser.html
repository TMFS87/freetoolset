❓ FAQ

Does it decode percent-encoded characters?

Yes. Query parameter values are automatically URL-decoded so you can read them clearly.

What if the URL is invalid?

The parser uses the browser's built-in URL parser; invalid input shows an error instead of partial results.

Can I see query params as a list?

Yes. Each key–value pair is listed separately for easy inspection.

📖 深入了解 URL Parser

为什么需要 URL 解析

调试接口、排查跳转、拼接链接时，经常要确认网址各部分是否正确。肉眼拆分长 URL 容易漏看参数。

背后的原理

工具调用浏览器原生的 URL 接口，把字符串拆成结构化字段（协议、主机、端口、路径、参数、锚点），并对参数做解码。

一个例子

把一条带追踪参数的推广链接粘进来，点解析后，你能清楚看到真实域名、路径以及被隐藏的 utm 参数。
