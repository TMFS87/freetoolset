🔐 JWT Encoder

Build a signed JWT (header.payload.signature) using HMAC-SHA256. Enter a JSON payload and a secret — signing happens in your browser.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Enter a JSON payload.
  2. Enter a secret key.
  3. Click Generate to sign with HS256.
  4. Copy the resulting token.

❓ FAQ

What algorithm does this use?

HMAC-SHA256 (HS256). The token is signed, not encrypted — anyone with the token can read the payload, only the secret proves it was signed by you.

Is the secret sent anywhere?

No. All signing uses the Web Crypto API in your browser; the secret never leaves your device.

Can I verify a token here too?

This tool focuses on encoding/signing. For verification, compare the signature with your backend or a verify tool.

❓ 常见问题（中文）

用的是什么算法？

HMAC-SHA256（HS256）。Token 是被“签名”而非“加密”——任何人都能读载荷，只有密钥能证明签名出自你。

密钥会被上传吗？

不会。签名全部用浏览器内置的 Web Crypto API 完成，密钥始终留在你的设备上。

📖 深入了解 JWT Encoder

JWT 结构

JWT 由三部分用点连接：header（算法与类型）、payload（声明数据）、signature（签名）。

签名过程（HS256）

1. base64url 编码 header 与 payload

2. 拼接 data = encHeader + "." + encPayload

3. 用密钥对 data 做 HMAC-SHA256

4. base64url 编码签名，得到 token = data + "." + sig

重要提醒

  • JWT 是“签名”不是“加密”，payload 可被任何人解码读取
  • 不要把敏感信息放进 payload
  • 本工具仅在本地浏览器签名，密钥不上传
