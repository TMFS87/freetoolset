🔄 CSV to JSON

Convert CSV data to a JSON array of objects. Handles quoted fields, commas inside values and custom delimiters.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste your CSV data (first row as headers).
  2. Choose the delimiter if not a comma.
  3. Click Convert to generate JSON.
  4. Copy the JSON array output.

❓ FAQ

Does the first row become keys?

Yes. The first row is treated as the header, and each following row becomes an object using those keys.

Are quoted fields supported?

Yes. Fields wrapped in double quotes may contain commas, quotes and line breaks.

What delimiters work?

Comma, semicolon and tab are supported via the delimiter selector.
