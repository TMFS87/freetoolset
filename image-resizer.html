🖼️ Image Resizer

Resize a JPG/PNG/WEBP image to a target width or height. Processing is done locally with the Canvas API — your photo never leaves the device.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Choose an image file.
  2. Set a target width (height auto) or both.
  3. Click Resize.
  4. Download the result.

❓ FAQ

Is my image uploaded?

No. The file is read and processed entirely in your browser via the Canvas API. Nothing is sent to a server.

What formats are supported?

Input: most browsers accept JPG, PNG and WEBP. Output is PNG by default to avoid quality loss; you can switch to JPG.

Will resizing reduce quality?

Downscaling generally looks good. Upscaling beyond the original size can look blurry because no new detail is invented.

图片会被上传吗？
