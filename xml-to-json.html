🔄 XML to JSON Converter

Convert XML into JSON for easier parsing in JavaScript and other languages. Attributes, nested elements and text are preserved.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste your XML.
  2. Click Convert.
  3. Copy the JSON result.
  4. Fix any well-formedness error shown.

❓ FAQ

How are attributes handled?

Attributes are placed under an "@attributes" object on the element. Repeated sibling elements with the same tag become an array.

What about the root element?

The root tag name is preserved as the top-level key in the output object.

Does it need valid XML?

Yes — the XML must be well-formed (matched tags, quoted attributes). The browser parser will report errors otherwise.

❓ 常见问题（中文）

属性怎么处理？

属性会放在该元素的 “@attributes” 对象下；同名同级元素会被合并成数组。

根元素怎么保留？

输出 JSON 的最外层键会保留根标签名。

📖 深入了解 XML to JSON Converter

为什么转换

许多旧系统、银行接口、RSS 仍输出 XML，而现代前端更习惯 JSON。转换后更易处理。

映射规则

  • 元素 → 对象键
  • 属性 → “@attributes” 子对象
  • 文本 → “#text”
  • 同名兄弟元素 → 数组

    • 注意

  • XML 必须格式良好（标签配对、属性加引号）
  • 转换在浏览器本地完成，数据不上传
