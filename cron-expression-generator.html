⏰ Cron Expression Generator

Build and understand cron schedules. Pick minute, hour, day, month and weekday to generate a crontab expression with a plain-English description.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Pick a preset or set each field manually.
  2. Use * for every value or a specific number.
  3. The cron expression updates automatically.
  4. Read the plain-English description to confirm.

❓ FAQ

What is the cron field order?

Minute, Hour, Day-of-month, Month, Day-of-week — five fields separated by spaces.

What does * mean?

An asterisk means "every" value for that field, e.g. * in the hour field means every hour.

Can I use step values?

Yes, the presets include steps like */5 (every 5 minutes). You can also type any field manually.

Cron表达式生成器需要联网吗？

不需要。所有处理都在你的浏览器本地完成，数据不上传服务器，离线也能用。

在浏览器性能范围内支持较大内容处理；具体上限取决于你的设备内存。
