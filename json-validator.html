❓ FAQ

How does it show errors?

It uses the browser JSON parser and reports the error text, which usually includes the approximate position of the problem.

Does it fix the JSON for me?

No. It tells you what is wrong; you fix it. Valid input is pretty-printed with indentation for clarity.

Is large JSON supported?

Yes for typical payloads. Extremely large files may be slow since everything runs in the browser.

📖 深入了解 JSON Validator

为什么需要 JSON 校验

JSON 是接口与配置的事实标准，一个多余的逗号或缺失的引号就会让整段解析失败。提前校验能省下大量调试时间。

背后的原理

工具把输入交给浏览器 JSON 解析器：成功则返回格式化后的对象，失败则捕获异常并展示错误描述（通常含位置），帮助你快速定位。

一个例子

一段接口返回的 JSON 报解析错误，粘进来点校验，立刻看到「位置 142 附近意外字符」，对照修好即可。
