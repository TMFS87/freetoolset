🎯 Random Name Picker

Drop in a list of names and pick one (or several) at random. Perfect for giveaways, classroom calls, and fair team selections.

Add names and click Pick.
🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste names, one per line.
  2. Choose how many to pick.
  3. Click "Pick".
  4. See the randomly selected name(s).

❓ FAQ

Can it pick multiple names?

Yes. Set the count and it draws that many names without repeating the same entry in one pick.

Are names uploaded?

No. Everything stays in your browser; nothing is sent to a server.

Can I pick with replacement?

Each pick avoids duplicates within a single draw. Click again to draw a fresh set.

📖 深入了解 Random Name Picker

为什么需要随机点名

抽奖、点名、选人时，人工挑容易被人情和偏见影响。随机抽选既公平又可复现过程。

背后的原理

工具把名单按行存入数组，用洗牌算法随机取前 N 个，并在一次抽取内避免重复。

一个例子

把 30 个学员名字粘进来，设抽 3 个，点一下就得到 3 名幸运者，过程透明公正。
