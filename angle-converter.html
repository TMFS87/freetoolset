❓ FAQ

How do I convert degrees to radians?

Multiply by π/180. So 180° = π ≈ 3.14159 rad, and 90° = π/2 ≈ 1.5708 rad.

Why do programming languages use radians?

Math functions like Math.sin() in JavaScript, Python and C all expect radians. Passing degrees directly is one of the most common bugs in graphics code.

❓ 常见问题（中文）

度和弧度怎么换算？

弧度 = 度 × π/180。所以 180° = π ≈ 3.14159 弧度，90° = π/2 ≈ 1.5708 弧度。

为什么编程里要用弧度？

JavaScript、Python、C 等语言的 sin/cos 函数都接收弧度。直接传角度值是图形和游戏开发中最常见的 bug 之一。

角度的几种表示法

  • **度（°）**：把一圈分成 360 份，源自古巴比伦的六十进制，日常最常用
  • **弧度（rad）**：弧长等于半径时对应的圆心角，一圈为 2π，数学和编程的标准单位
  • **百分度（gon/grad）**：把一圈分成 400 份，直角正好是 100，测绘领域使用
  • **圈（turn）**：一整圈为 1，动画和旋转参数中直观好用

    • 关键换算关系

  • 1 圈 = 360° = 2π rad ≈ 6.28319 rad = 400 gon
  • 1° = 60 角分（′）= 3600 角秒（″）
  • 1 rad ≈ 57.2958°

    • 编程中的常见坑

    JavaScript 的 `Math.sin(90)` 不会返回 1，因为它把 90 当作弧度处理。正确写法是 `Math.sin(90 * Math.PI / 180)`。这个错误在 Canvas 绘图和 3D 旋转中尤其高发。

    角分角秒的用途

    经纬度坐标常写成「39°54′27″N」这种度分秒格式，天文观测和 GPS 定位也大量使用角秒作为精度单位。
