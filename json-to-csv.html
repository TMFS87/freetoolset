📊 JSON to CSV

Convert a JSON array of objects into CSV. Automatically builds the header row and safely quotes values with commas or quotes.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Paste a JSON array of objects.
  2. Click Convert to generate CSV.
  3. Fix any JSON errors reported.
  4. Copy the CSV or paste it into a spreadsheet.

❓ FAQ

What JSON shape is required?

An array of flat objects, e.g. [{"a":1,"b":2}, ...]. Keys across objects are merged into the header row.

How are special characters handled?

Values containing commas, quotes or line breaks are wrapped in double quotes with quotes escaped, per CSV rules.

Are nested objects supported?

Nested values are serialized as JSON strings within the cell. Flatten your data first for best results.
