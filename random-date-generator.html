📅 Random Date Generator

Generate a random date between two dates (or within a year). Handy for giveaways, sampling, or just settling “which day”.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Set a start date.
  2. Set an end date.
  3. Click Generate.
  4. Use the date or roll again.

❓ FAQ

Can I generate only weekdays?

This simple version picks any calendar day uniformly. For weekdays-only, just reroll if a weekend appears.

What range can I use?

Any two dates; the start must be before the end. You can span years.

Is it useful for giveaways?

Yes — picking a random date, then a random entry from that day, is a common fair-draw technique.
