🔡 ROT13 / Caesar Cipher

Apply a Caesar cipher to text — shift every letter by a chosen number of positions (ROT13 = shift 13). Encode a message or decode a cipher.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Type or paste your text.
  2. Set the shift (13 for classic ROT13).
  3. Click Encode / Decode.
  4. Copy the result. (ROT13 is its own inverse.)

❓ FAQ

What is ROT13?

A Caesar cipher with a shift of 13. Because the alphabet has 26 letters, applying it twice returns the original text — encode and decode are the same operation.

Does it change numbers and punctuation?

No — only letters A–Z / a–z are shifted. Digits, spaces and symbols are left untouched.

Is this real encryption?

No. ROT13 is trivially reversible and offers no security; it is for fun, puzzles and obfuscation, not protection.

❓ 常见问题（中文）

什么是 ROT13？

平移 13 位的凯撒密码。因为字母表有 26 个字母，平移两次会还原原文，所以“加密”和“解密”是同一操作。

数字和标点会变吗？

不会。只有 A–Z / a–z 被平移，数字、空格和符号保持不变。

📖 深入了解 ROT13 / Caesar Cipher

凯撒密码原理

把字母表中的每个字母向后移动 N 位（到末尾则回到开头）。ROT13 取 N=13，因 26 个字母，移两次即还原。

规则

  • 仅平移 A–Z / a–z，保留大小写
  • 数字、空格、标点原样保留
  • N=13 时编码=解码

    • 提醒

    这不是真正的加密，无任何安全性，只用于趣味与混淆。
