❓ FAQ

What YAML features are supported?

Nested maps, lists, strings, numbers, booleans and null. Anchors, aliases and complex multi-line blocks are not supported — keep input simple.

How are lists detected?

Lines starting with "- " under a key become array items; their indentation sets the nesting level.

Will it handle tabs?

Use spaces for indentation. Mixed tabs may produce unexpected nesting.

❓ 常见问题（中文）

支持哪些 YAML 特性？

支持嵌套字典、列表、字符串、数字、布尔与空值；锚点、别名和复杂多行块暂不支持，输入请保持简单。

怎么识别列表？

键下以「- 」开头的行视为数组项，缩进决定嵌套层级。

📖 深入了解 YAML to JSON Converter

为什么需要 YAML 转 JSON

YAML 可读性高、常用于配置；JSON 则是接口与前端的事实标准。把前者转成后者是开发与运维的日常。

背后的原理

工具按缩进构建层级，把「key: value」解析为对象属性，把「- 」行解析为数组，再序列化为 JSON。它覆盖常见结构，不处理锚点等高级语法。

一段 docker-compose 风格的 YAML 粘进来，转成 JSON 后可直接贴进需要 JSON 配置的后台。
