❓ FAQ

Is UA parsing reliable?

It is heuristic — based on known tokens. Modern browsers also "lie" via UA reduction, so results are best-effort, not guaranteed.

What can a UA tell me?

Roughly the browser family/version, OS, whether it is mobile/tablet/desktop, and the rendering engine (Blink, WebKit, Gecko).

Should I block users by UA?

Not recommended — UAs are easily spoofed. Use feature detection or server-side capability checks instead.

❓ 常见问题（中文）

UA 解析可靠吗？

它是基于已知特征串的启发式判断。现代浏览器还在做 UA 缩减（UA reduction），所以结果仅供参考，并非绝对准确。

能通过 UA 判断什么？

大致能看出浏览器家族与版本、操作系统、设备是手机/平板/桌面，以及渲染引擎（Blink、WebKit、Gecko）。

📖 深入了解 User Agent Parser

User-Agent 是什么

UA 是浏览器访问网站时发送的一串自我描述文本，包含浏览器、引擎、操作系统等信息。

解析逻辑

本工具用一组正则匹配常见特征：Chrome/Edge/Firefox/Safari、Windows/macOS/iOS/Android/Linux、Blink/WebKit/Gecko 引擎、iPhone/iPad/Android 设备。

局限与注意

  • UA 可被伪造，不可作为安全依据
  • 浏览器正逐步缩减 UA 信息（UA reduction），未来可解析内容会更少
  • 结果仅供参考
