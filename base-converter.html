❓ FAQ

What bases are supported?

This tool converts between binary (2), octal (8), decimal (10), and hexadecimal (16) — the most common bases in programming.

Why is my input rejected?

Each base only allows certain digits. Binary allows 0–1, octal 0–7, decimal 0–9, and hex 0–9 plus A–F. An invalid digit (like "2" in binary) produces an error.

Is hex case-sensitive?

Output is shown uppercase (e.g. FF). Input accepts both upper and lower case (ff = FF).
