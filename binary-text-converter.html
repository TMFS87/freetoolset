0️⃣ Text to Binary Converter

Convert text to binary code and decode binary back to text. Uses 8-bit ASCII/UTF-8 encoding with space-separated bytes.

🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Type text in the top box to see binary below.
  2. Or paste space-separated binary to decode to text.
  3. Use the swap direction toggle as needed.
  4. Copy the output with the copy button.

❓ FAQ

What encoding is used?

Each character is encoded as its UTF-8 byte(s), shown as 8-bit binary groups separated by spaces.

How do I decode binary?

Paste 8-bit binary groups separated by spaces into the binary box and the text appears automatically.

Does it support emoji?

Yes, multi-byte UTF-8 characters like emoji are encoded across several bytes.
