⏱️ Online Countdown Timer

A simple online countdown timer with quick presets (1, 5, 10, 30 minutes) and a custom time. Hear a beep when time is up — no install needed.

📋 How to Use

  1. Pick a preset or enter minutes/seconds.
  2. Press Start to begin the countdown.
  3. Pause or Reset anytime.
  4. Listen for the beep when it reaches zero.

❓ FAQ

Does it keep running if I close the tab?

No — the timer lives in this tab, so keep it open while counting.

Can I use it as a Pomodoro timer?

Yes, set 25 minutes for focus and 5 for a break.

Is there a sound alert?

Yes, a short beep plays when the countdown ends.
