⏱️ Online Stopwatch

A clean online stopwatch that counts up from zero with start, stop and lap. Great for workouts, experiments and time trials — runs right in your browser.

00:00.00
🔒 All processing happens in your browser. No data is uploaded to any server.

📋 How to Use

  1. Press Start to begin counting up.
  2. Press Lap to record split times.
  3. Press Stop to pause, Start to resume.
  4. Press Reset to return to zero.

❓ FAQ

How accurate is it?

It uses the browser clock and is accurate enough for everyday timing; extreme precision may drift slightly.

What are laps for?

Laps capture split times so you can compare intervals within one run.

Does it run in the background?

It keeps running while the tab is open, though heavy load can cause minor jitter.
