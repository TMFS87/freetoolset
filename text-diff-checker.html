📋 How to Use

  1. Paste the original text in the left box.
  2. Paste the new version in the right box.
  3. Click "Compare" to see changed lines highlighted.
  4. Review additions (green) and removals (red).

❓ FAQ

Is this a character-level or line-level diff?

It compares line by line. Lines present only in the first text are marked removed, only in the second are added, and lines in both but different are flagged as changed.

Can I compare code snippets?

Yes. It works great for short code or config snippets, though for very large files a dedicated merge tool may be more efficient.

Is my text stored?

No. Comparison runs entirely in your browser.

❓ 常见问题（中文）

对比是按行还是按字符？

按行对比。只在原文出现的行标为删除，只在新文出现的标为新增，两边都存在但内容不同的标为已修改。

能对比代码吗？

可以，适合短代码或配置片段的改动核对。

📖 深入了解 Text Diff Checker

为什么需要文本对比

在写作、协作和开发中，我们经常需要确认「改了哪里」。逐行对比能直观呈现新增、删除和修改，比肉眼比较可靠得多。

背后的原理

工具把两段文本按换行切分为行数组，用集合运算找出仅出现在左侧（删除）、仅出现在右侧（新增）的行，并对两边都有的行做内容比较标记是否变化。

一个例子

把旧版文案放左边、新版放右边，点击对比后，新增的卖点句显示为绿色，删掉的过时表述显示为红色，一眼就能审稿。
