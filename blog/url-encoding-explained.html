URL 编码原理：为什么网址里的中文会变成 %E4%...

当你在地址栏看到 %E4%B8%AD 这样的字符，那就是 URL 编码（百分号编码）的功劳。它让中文和特殊符号能安全地出现在网址里。

为什么需要 URL 编码

URL 只允许一部分 ASCII 字符。空格、中文、&、= 等字符会被误解，必须编码为 % 加两位十六进制。

encodeURI 与 encodeURIComponent

  • encodeURI 保留 ? # / 等结构字符，用于整条网址
  • encodeURIComponent 编码得更彻底，用于单个参数值
  • 拼接查询字符串时应使用后者
