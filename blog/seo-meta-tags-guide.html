SEO Meta Tag Optimization: How to Write Titles & Descriptions People Click

In search results, users see the title and description first. Good meta tags directly lift click-through rate (CTR), which in turn affects ranking.

How to write the title

  • Keep 50–60 characters to avoid truncation
  • Front-load the core keyword
  • Include the brand name for trust
  • Unique per page, no stuffing

How to write the description

Descriptions don't directly affect ranking but decide whether users click. Use 120–155 characters to summarize the value proposition with a call to action.
