Morse Code Basics: Sending Messages in Dots and Dashes

Morse uses '·' (dit) and '—' (dah) for letters and numbers. E is the shortest '·', T is '—', and SOS is '···———···'.

Memory tricks

  • Learn common letters first: E T A N S O
  • Digits increase from 1 to 5 symbols
  • Group practice beats rote memorization

Modern uses

Radio hobbyists, emergency communication, and as a fun cipher remain active.

💡 Use a Morse translator to see code from text, or decode text from code — learn while playing.
