CSV 与 JSON 互转：表格数据搬家风

CSV 是表格（逗号分隔），JSON 是结构化对象。把 Excel 导出的 CSV 转成 JSON，才能喂给接口；反过来把接口数据导成 CSV，方便在表格里看。

转换要点

  • 字段内含逗号要用引号包住
  • 自定义分隔符（如分号）要指定
  • JSON 数组转 CSV 自动生成表头

典型流程

Excel → 另存 CSV → 转 JSON → 调接口；或 接口 JSON → 转 CSV → 用 Excel 分析。
