Test regular expressions against your text in real time. Matches are highlighted and every capture group is listed.

    📋 How to Use

    1. Type a pattern in the "Regular Expression" box (no slashes needed).
    2. Add flags like gi in the small box if needed.
    3. Enter your test text below — matches highlight instantly.
    4. Review the match list for positions and capture groups.

    ❓ FAQ

    Do I need the slashes?

    No. Enter just the pattern, e.g. \d+. Slashes (/\d+/) are a JavaScript literal syntax and are not used here.

    Why no matches with a valid pattern?

    Check your flags. Without the g (global) flag only the first match is found; this tester always uses g internally so all matches show. Also confirm case sensitivity (i) and multiline (m).

    What are capture groups?

    Parentheses ( ) in a pattern capture sub-parts. The match list shows each group's value after the position, e.g. groups: ["hello","freetoolset.app"].
